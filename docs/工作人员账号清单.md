# 工作人员账号清单

> 账号存储在数据库 `staff` 表，后端首次启动时自动初始化种子账号。登录账号即姓名；口令以加盐哈希存储，不明文落库。

## 初始口令规则

| 角色 | 初始密码 | 说明 |
| --- | --- | --- |
| 管理员 admin | 环境变量 `ADMIN_PASSWORD`，未设置时默认 `change-me` | 可在控制台切换一面/二面场次、查看全部组别、结果管理 |
| 面试官（A-D 组） | `123456`（统一初始密码） | 仅能进入当前开放场次的本组工作台，跨组不可见 |
| 流动人员 | `123456`（统一初始密码） | 仅进入签到分流台，可查看全部考生并签到、分组，不进入打分工作台 |

> 上线前请务必通过环境变量修改管理员口令，并在首次使用后统一更换 `123456` 初始密码。

## 权限与场次规则

- **场次锁定**：管理员在控制台切换当前场次（一面 / 二面）。一面阶段面试官只能进入一面工作台，二面阶段只能进入二面工作台；同一批 A-D 面试官随场次切换，管理员不受限制。
- **分组隔离**：A/B/C/D 各组的队列、叫号、打分互不可见，仅管理员可查看全部组别。
- **流动人员**：不进入任何打分工作台；在分流台可查看全部考生并执行签到、分组操作。
- 新增 / 调整工作人员时，直接在 `staff` 表中维护对应账号、角色、分组与口令哈希即可，无需重启即可生效（口令修改后下次登录校验）。
